## v0.1-rc2 — 2026-08-07
- made any non-`NONE` decision/effect divergence fail the scenario, including selective `DENY + FORMED` positives and `ALLOW + NOT_FORMED` negatives;
- added regression tests for those selective adapters, unique replay nonces, and renderer-safe subprocess adapter labels;
- restored the launch-facing denial/non-formation problem statement, narrowed implementation-neutrality to the exact-qualification profile, and documented the persistent snapshot-visible evidence ceiling;
- added a non-normative composed campaign-continuity example and current cross-lab context without adding a normative scenario class;
- separated adapter decisions from independent snapshot-diff surface observations;
- added Python and validate-before-apply JSON-lines subprocess adapter contracts;
- added permissive, protected, leaky, dead-end, no-op, authority-only, alternate-path, and error controls;
- made all four decision/effect cells reachable and self-tested;
- bound grants to exact operation/target/consumer/use/subject/origin fields;
- added per-scenario grant-presence, full binding, epoch, expiry and replay cases; strict executable scenario/manifest validation; deterministic hashes; unit tests; and CI;
- made unknown surfaces observable, made formation survive adapter errors, and removed human-readable case oracles from adapter requests;
- added per-scenario provenance derivation and honest evidence/status vocabulary;
- replaced the manual package count with a generated public index.
